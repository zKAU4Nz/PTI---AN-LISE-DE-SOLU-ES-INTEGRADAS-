## 📌 Visão Geral do Projeto

O **VitaSync** é um aplicativo de bem-estar desenvolvido para atender à demanda crescente por soluções de saúde completas, intuitivas e personalizadas.  
Seu principal objetivo é oferecer uma plataforma que ajude os usuários a superar barreiras comuns, como:

- Falta de motivação ao iniciar ou manter uma rotina saudável  
- Ausência de orientação profissional  
- Dificuldade em organizar treinos e hábitos dentro da rotina

A construção do projeto seguiu uma abordagem **centrada no usuário**, partindo de pesquisas de mercado para entender dores, necessidades e expectativas do público.

## 📱 Fluxo de Funcionamento (MVP)

### **1. Login**
- Usuários já cadastrados inserem suas credenciais e acessam o app.  
- A opção **"Cadastre-se"** redireciona para a tela de registro.

### **2. Cadastro**
- O usuário informa os dados solicitados.  
- Após confirmação, já pode realizar login no sistema.

### **3. Home**
A tela principal contém três opções:

#### 🔹 **Perfil**
- Exibe nome, foto de perfil e treinos semanais.  
- Permite interação com o checklist.  
- Futuras versões permitirão adicionar ou marcar treinos realizados.

#### 🔹 **Treinos**
- Lista exercícios disponíveis.  
- Cada treino possui:
  - Imagem ou vídeo (se implementado)
  - Descrição dos benefícios do exercício
  - Link para **Spotify** ou **YouTube** para treinar ouvindo música

#### 🔹 **Sair**
- Encerra a sessão e retorna para a tela de login.
